# RatpacCheck — 100% Native WordPress Theme

A premium, science-backed haircare and skincare WordPress theme crafted with clinical elegance and creator-backed aesthetics.

---

## 📦 Deliverables in this Repository

- **`ratpaccheck-theme.zip`**: The ready-to-upload WordPress Theme ZIP file for immediate client delivery.
- **`wordpress-theme/ratpaccheck/`**: The complete, uncompressed WordPress theme directory (PHP templates, compiled CSS, JS, and product media).
- **`README-WORDPRESS.md`**: Complete client setup and page configuration guide.

---

## 🚀 Quick Install (WordPress Admin)

1. Log in to your WordPress dashboard (`https://yourdomain.com/wp-admin`).
2. Navigate to **Appearance** &rarr; **Themes** &rarr; **Add New Theme**.
3. Click **Upload Theme** at the top.
4. Select `ratpaccheck-theme.zip` and click **Install Now**.
5. Click **Activate**.

For detailed setup instructions on creating pages and assigning templates, see [README-WORDPRESS.md](./README-WORDPRESS.md).

---

## 🛠️ Theme Technical Specifications

- **Theme Engine**: 100% Native PHP 7.4/8.x+, standard WordPress Theme Hierarchy.
- **Styling**: Production-compiled Tailwind CSS in `assets/css/main.css` (zero build step needed by the user).
- **Interactivity**: Lightweight Vanilla JS in `assets/js/theme.js` (Cart Drawer, Mobile Nav, Accordions, Search Modal).
- **Admin Management**: Registered Custom Post Type `ratpac_product` with Custom Taxonomies (Categories & Concerns) and meta boxes for pricing, rating, and badges.
- **Dependencies**: 0 Node.js dependencies in production. Runs on any standard Apache/Nginx + PHP + MySQL WordPress host.
